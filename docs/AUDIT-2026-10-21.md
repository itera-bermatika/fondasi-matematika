# Audit bacaan interaktif — 21 Oktober 2026

## Lingkup dan hasil

- Seluruh 41 dokumen HTML diperiksa untuk berkas/tautan lokal, tujuan bagian, dan ID ganda. Lulus setelah perbaikan.
- Seluruh 41 halaman publik dibuka pada viewport 390 × 844. Setelah renderer siap: tidak ada galat MathJax, MathML sumber yang belum terkonversi di luar keluaran aksesibilitas MathJax, atau luapan horizontal dokumen.
- Seluruh 29 rangkaian pengujian aktivitas lulus. Pengujian mencakup perhitungan, batas domain, kasus khusus, dan penilaian jawaban sesuai cakupan masing-masing berkas uji.
- Seluruh JavaScript tingkat atas di dist lolos pemeriksaan sintaks.
- Telaah konsep terarah pada pangkat/akar, faktorisasi, pertidaksamaan, invers, limit tak hingga, dan garis singgung tidak menemukan kesalahan konsep baru. Syarat bukan nol, akar utama, pembatasan domain, arah limit, serta perbedaan kontinuitas dan turunan sudah dijelaskan.

## Temuan dan perbaikan

1. Pencarian hanya memeriksa nama/deskripsi kelompok sehingga judul seperti faktorisasi tidak ditemukan. Kini judul seluruh tautan bacaan ikut dicari. Diuji dengan faktorisasi, radian, hasil kosong, dan menghapus pencarian.
2. Beranda menyebut dua bacaan berbeda sebagai bacaan pertama. Label kesetaraan kini menyebut topiknya, sedangkan jalur awal tetap dimulai dari bilangan.
3. Urutan operasi belum mempunyai tautan lanjut, dan pangkat/akar melompati kesetaraan. Kini jalur berurutan: urutan operasi → pangkat/akar → kesetaraan → variabel. Jalur ini ditelusuri melalui antarmuka ponsel.
4. Rute #beranda dan #bacaan bekerja melalui JavaScript tetapi belum mempunyai ID tujuan nyata. ID ditambahkan tanpa mengubah rute lama.
5. Keterangan peta masih menyebut bagian rencana pengembangan, dan README masih menyebut sebelas bacaan. Keduanya disesuaikan dengan isi saat ini.
6. Pemeriksa penerbitan sebelumnya hanya memeriksa keberadaan berkas. Kini juga menolak ID ganda dan tautan bagian HTML yang tidak ditemukan.

## Batas audit dan prioritas lanjutan

Pemeriksaan seluruh halaman di browser menggunakan browser dalam aplikasi pada ukuran ponsel; ini bukan sertifikasi pengujian fisik semua perangkat, Chrome, Edge, atau pembaca layar. Pemeriksaan lebar dokumen tidak menjamin setiap label grafik atau formula kecil sudah ideal secara visual. Telaah konsep bersifat terarah, bukan penyuntingan setiap kalimat dan pembuktian seluruh soal secara independen.

Prioritas berikutnya: uji coba belajar dengan mahasiswa, pemeriksaan keyboard/pembaca layar, dan penyuntingan bab demi bab berdasarkan kesulitan nyata pembaca. Jangan menafsirkan cek kesiapan sebagai tes penempatan atau kelulusan yang tervalidasi.
